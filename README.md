# Fates OFA — One For All

A Hypixel SkyBlock quality-of-life mod for Fabric (Minecraft 26.2 and 26.3): items and storage,
activity trackers, dungeons, Kuudra and a progression planner in one mod. **Display only** — it never
clicks, moves or plays for you — and it needs **no account**.

Status: early development. Licence: GPL-3.0-only.

## Building

Builds run on GitHub Actions (JDK 25): `./gradlew build -Pmc=26.2` or `-Pmc=26.3` →
`build/libs/fatesofa-<version>+mc<mc>.jar`. Install with Fabric Loader and Fabric API for the same
Minecraft version.
